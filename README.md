# Bezero-inguruneko programazioa — errepaso materiala

DAWko **Bezero-inguruneko programazioa** modulua errepasatzeko materiala: JavaScript, arrayak, objektuak, klaseak, DOM, gertaerak eta Web APIak.


## Fitxategiak

| Fitxategia | Edukia |
|---|---|
| `ERREPASOA.md` | Errepaso gida osoa, markdown formatuan. |
| `ERREPASOA.html` | Gida bera, nabigatzailean irakurtzeko eta inprimatzeko prestatuta. |
| `ERREPASOA.pdf` | Gidaren PDF bertsioa. |
| `DAW1_erreferentzia_EUS.html` | Kode-erreferentzia azkarra: 79 fitxa, bilaketa, kategoriak eta kopiatze-botoiak. |
| `10_ARIKETA_ERREPASOA.md` | 10 ariketa labur, soluzioekin. |
| `10_ARIKETA_ERREPASOA.html` | Ariketa berberak modu interaktiboan: egindakoak markatu, gaiaren arabera iragazi eta soluzioak zabaldu. |
| `LABURPENA.md` | Iturri-materialen laburpena eta ohiko akatsen zerrenda. |
| `errepaso-txantiloia.html` | HTML txantiloi hutsa, proba edo ariketa libreetarako. |

## Erabilera

- Ireki `.html` fitxategiak zuzenean nabigatzailean.
- Ez da zerbitzaririk, interneteko konexiorik ezta kanpoko mendekotasunik behar.
- `DAW1_erreferentzia_EUS.html` fitxategian `/` tekla erabil daiteke bilaketarako eta `Esc` bilaketa garbitzeko.
