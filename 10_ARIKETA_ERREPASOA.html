01 Klaseak

Liburua: klasea, metodoa eta metodo estatikoa

Sortu Liburua klasea constructor(izenburua, orrialdeak) eta laburpena() metodoarekin. Azken honek "Izenburua (N orrialde)" itzuli behar du. Gehitu static luzeena(liburuak) metodoa, orrialde gehien dituen liburua itzultzeko. Probatu hiru libururekin. 

class Liburua {
  // TODO: constructor, laburpena() eta static luzeena()
}
Pista

Metodo estatikoa klaseari dagokio: Liburua.luzeena(...). Barruan reduce erabil dezakezu.

Soluzioa erakutsiSoluzioa ezkutatu 
class Liburua {
  constructor(izenburua, orrialdeak) {
    this.izenburua = izenburua;
    this.orrialdeak = orrialdeak;
  }

  laburpena() {
    return `${this.izenburua} (${this.orrialdeak} orrialde)`;
  }

  static luzeena(liburuak) {
    return liburuak.reduce((luzeena, liburua) =>
      liburua.orrialdeak > luzeena.orrialdeak ? liburua : luzeena
    );
  }
}

const liburuak = [
  new Liburua("Kirmen Uribe", 120),
  new Liburua("Maddi Etxeberria", 240),
  new Liburua("Joseba Sarrionandia", 180),
];

console.log(liburuak[1].laburpena());
console.log(Liburua.luzeena(liburuak).izenburua); // "Maddi Etxeberria"
02 Klaseak

Tenperatura: getter, setter eta balidazioa

Sortu Tenperatura klasea. Barruko balioa _celsius izango da. celsius getterrak balioa itzuliko du; setterrak zenbaki bat dela egiaztatuko du eta, bestela, Error jaurtiko du. Gehitu fahrenheit getterra (C * 9/5 + 32). Probatu new Tenperatura(20) eta 0 balioarekin. 

class Tenperatura {
  constructor(celsius) {
    this.celsius = celsius; // setterra deitzen da
  }

  // TODO: get/set celsius, get fahrenheit
}
Pista

Getter eta setterrak propietate gisa erabiltzen dira: t.celsius = 0, ez t.celsius(0). Konstruktorean esleitzean setterra exekutatzen da.

Soluzioa erakutsiSoluzioa ezkutatu 
class Tenperatura {
  constructor(celsius) {
    this.celsius = celsius;
  }

  get celsius() {
    return this._celsius;
  }

  set celsius(balioa) {
    if (typeof balioa !== "number" || Number.isNaN(balioa)) {
      throw new Error("Tenperatura zenbaki bat izan behar da");
    }
    this._celsius = balioa;
  }

  get fahrenheit() {
    return this._celsius * 9 / 5 + 32;
  }
}

const t = new Tenperatura(20);
console.log(t.fahrenheit); // 68

t.celsius = 0;
console.log(t.fahrenheit); // 32
03 Klaseak

Tresna → Mugikorra: extends eta super

Sortu Tresna klasea (izena eta deskribatu() → "Tresna: izena"). Sortu Mugikorra azpiklasea extends erabiliz, marka propietate gehigarriarekin. Berridatzi deskribatu() super.deskribatu() erabiliz: "Tresna: Smartphone — Pixel". Egiaztatu instanceof Tresna. 

class Tresna {
  // TODO: constructor eta deskribatu()
}

class Mugikorra extends Tresna {
  // TODO: super(), marka eta deskribatu() berridatzia
}
Pista

super(izena) deitu behar da this erabili aurretik. Gurasoaren metodoa super.deskribatu() bidez deitzen da.

Soluzioa erakutsiSoluzioa ezkutatu 
class Tresna {
  constructor(izena) {
    this.izena = izena;
  }

  deskribatu() {
    return `Tresna: ${this.izena}`;
  }
}

class Mugikorra extends Tresna {
  constructor(izena, marka) {
    super(izena);
    this.marka = marka;
  }

  deskribatu() {
    return `${super.deskribatu()} — ${this.marka}`;
  }
}

const m = new Mugikorra("Smartphone", "Pixel");
console.log(m.deskribatu());      // "Tresna: Smartphone — Pixel"
console.log(m instanceof Tresna); // true

Noten batezbestekoa eta classList

Irakurri nota guztiak, kalkulatu batezbestekoa eta erakutsi #batezbestekoa elementuan "Batezbestekoa: 6.0" formatuan. Gainera, 5etik beherako notek gainditua klasea kenduta eduki dezatela, eta gaindituenek klase hori izan dezatela. Erabili querySelectorAll, spread, map, reduce eta classList.toggle.

  <li class="nota">6</li>
</ul>
<p id="batezbestekoa"></p>
// TODO: irakurri notak, kalkulatu batezbestekoa eta markatu gaindituak

Pista

querySelectorAll-ek NodeList bat itzultzen du. map erabili nahi baduzu, bihurtu array: [...notak].

06 DOM

data-mota atributua eta iragazketa

Bildu #produktuak zerrendako data-mota="fruta" duten elementuak, atera haien testua eta erakutsi #frutak paragrafoan koma bidez banatuta: "Sagarra, Banana". Erabili dataset eta filter/map. 

<ul id="produktuak">
  <li data-mota="fruta">Sagarra</li>
  <li data-mota="barazki">Azenarioa</li>
  <li data-mota="fruta">Banana</li>
  <li data-mota="barazki">Porrua</li>
</ul>
<p id="frutak"></p>
Pista

data-mota atributua elementua.dataset.mota bidez atzitzen da (kamelCase bihurtuta).

Soluzioa erakutsiSoluzioa ezkutatu 
const produktuak = [...document.querySelectorAll("#produktuak li")];

const frutak = produktuak
  .filter((li) => li.dataset.mota === "fruta")
  .map((li) => li.textContent);

document.querySelector("#frutak").textContent = frutak.join(", ");
07 Gertaerak

Inprimakia: submit, preventDefault eta balidazioa

Kudeatu submit gertaera: deitu preventDefault(), irakurri #izena balioa trim() eginez. Hutsik badago, erakutsi "Izena hutsik dago."; bestela "Kaixo, <izena>!" eta garbitu inprimakia. Ez utzi orria berriz kargatzen. 

<form id="forma">
  <input id="izena" type="text" placeholder="Zure izena">
  <button type="submit">Bidali</button>
</form>
<p id="mezua" role="status"></p>
Pista

preventDefault() gabe nabigatzaileak orria berriz kargatuko du. value beti da string.

Soluzioa erakutsiSoluzioa ezkutatu 
const forma = document.querySelector("#forma");
const mezua = document.querySelector("#mezua");

forma.addEventListener("submit", (e) => {
  e.preventDefault();

  const izena = document.querySelector("#izena").value.trim();

  if (!izena) {
    mezua.textContent = "Izena hutsik dago.";
    return;
  }

  mezua.textContent = `Kaixo, ${izena}!`;
  forma.reset();
});

10 localStorage

Objektua localStoragean: JSON.stringify / JSON.parse

Gorde { izena: "Ane", puntuazioa: 8 } objektua emaitza gakoan JSON gisa. Gero irakurri eta bihurtu objektu; gakoa ez badago edo JSONa baliogabea bada, erabili { izena: "Ezezaguna", puntuazioa: 0 } lehenetsia. Azkenik, erakutsi izena eta ezabatu gakoa.

Pista

Gordetzeko JSON.stringify; irakurtzeko JSON.parse. Erabili try/catch JSON baliogabea kudeatzeko.

Soluzioa erakutsiSoluzioa ezkutatu 
const gakoa = "emaitza";
const lehenetsia = { izena: "Ezezaguna", puntuazioa: 0 };

localStorage.setItem(
  gakoa,
  JSON.stringify({ izena: "Ane", puntuazioa: 8 })
);

let emaitza = lehenetsia;

try {
  const gordea = localStorage.getItem(gakoa);
  if (gordea) {
    emaitza = { ...lehenetsia, ...JSON.parse(gordea) };
  }
} catch {
  emaitza = lehenetsia;
}

console.log(emaitza.izena); // "Ane"
localStorage.removeItem(gakoa);
